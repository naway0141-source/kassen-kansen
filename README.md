# 合戦観戦｜一戦入魂・戦術観戦ゲーム

ランダム生成の戦場で、将たちが勝手に戦うのを見ているだけの観戦ゲームです。
架空戦史観戦ソフトの名作へのオマージュとして、「大陸の興亡」ではなく
**1枚の戦術マップ・1合戦だけ**に絞って作りました。

## 遊び方（眺め方）

1. 主人公の **名前・統率・武勇・知略・兵数** を決める（プリセットあり）
2. 形式を選ぶ：**野戦** / **攻城戦**（攻城戦は攻め手・守り手も選択）
3. 「出陣」を押したら、あとは観戦。速度は ⏸／×1／×2／×4

## 仕様

- **戦場は毎回ランダム生成**：起伏（高地ボーナス）、森（防御・隠蔽）、そして川は **あったりなかったり**（ある場合は橋と浅瀬が要所になる）
- **将の個性**：全将に能力値とタイプがある ― 名将⭐／策士🦊／脳筋🐗／猛将🔥／臆病🐇／無能💤／凡将😐。タイプで狙う相手も逃げ足も変わる
- **士気と潰走**：兵が減ると士気が崩れて潰走。総大将が倒れると敗北
- **伏兵**：森に潜んで敵には見えない（観戦者には半透明で見える）。近づかれると奇襲
- **援軍**：劣勢になった軍に、途中で新しい部隊が駆けつけることがある
- **攻城戦**：城門はHP制。破って本丸を落とせば攻め手の勝ち、制限時間（8分）を守り切れば守備側の勝ち
- 戦況ログが時系列で流れ、終了後に主人公の戦績（与えた被害・撃破数・生死）と殊勲者が表示される

## 技術メモ

- 単一HTMLファイル。ロジック（生成・経路探索・合戦シミュレーション）と描画を分離
- 地形は連続標高からローポリ風ファセット＋陰影で立体描画（開戦時にオフスクリーンへ描画）。森は三角の木、城壁はブロック、本丸は二重の櫓
- 兵は点の隊列で表示（1点≒55人）。隊列は進行方向を向き、兵が減ると点が減り、潰走すると隊列が崩れて散る。軍旗は隊列の後方（主人公は金、総大将は金の玉つき）
- 経路探索はダイクストラ（バイナリヒープ）。到達不能な目標への再探索は抑制している
- Nodeハーネスで合戦を数百回ヘッドレス実行し、決着率・所要時間・勝敗バランスを検証済み。UIはDOMスタブのスモークテストで初期化〜描画まで確認
